# Zomato Analytics Dashboard

## Project Overview
A data analytics project built to analyze Zomato restaurant data and generate meaningful business insights using Python, MySQL, Power BI, Excel, HTML, CSS and Flask.

## Tools & Technologies
- Python
- Pandas
- MySQL
- Excel
- Power BI
- Flask
- HTML
- CSS

## Key Analysis
- Total Revenue
- Total Orders
- Total Restaurants
- Average Restaurant Rating
- Top 10 Restaurants by Revenue
- City-wise Revenue Analysis
- Rating-wise Restaurant Analysis
- Delivery Time Analysis

## Dashboard KPIs
- Total Revenue: ₹90,433,000
- Total Orders: 207,227
- Total Restaurants: 150
- Average Rating: 3.93
